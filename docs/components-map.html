OTT Release Radar — how it works

Every Friday evening, Naman gets one Telegram message listing what's new this week on Netflix, Prime Video and JioHotstar in India, filtered to his tastes, with an AI watch-or-skip call on each title.

Live appGitHub repository

Problem

Naman spends 20 minutes every Friday scrolling three apps to find what's new, because the apps push trending titles instead.

Outcome

One message a week with only new titles that fit his taste, a clear watch-or-skip call on each, and a link straight into the app.

Reliability and cost

Runs on free plans. If one data source or AI model is down, the digest still goes out. API use is cached and capped so the monthly quota lasts.
