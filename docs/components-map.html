OTT Release Radar

Every Friday at 7:00 PM IST, this app finds the shows and films that released in India in the last seven days on Netflix, Prime Video and JioHotstar, keeps the ones that match Naman's genres and languages, asks Gemini Flash whether each is worth watching, and sends the digest to Telegram.

GitHub repository Stack: Next.js 16 · Vercel Cron · TMDB · Gemini Flash · Telegram Bot API

Pipeline

One run of GET /api/digest, top to bottom. Solid boxes are modules in this repo; dashed boxes are the outside services they call.

Module in this repoExternal service
1Trigger

Digest API route

src/app/api/digest/route.ts · vercel.json
  • Runs on cron 30 13 * * 5 (Friday 13:30 UTC = 7:00 PM IST)
  • Cron calls carry Bearer CRON_SECRET; the homepage uses ?manual=true
  • ?send=false returns the digest as JSON without messaging Telegram

Vercel Cron + Functions

  • Hosts the app and fires the weekly schedule
  • Function limit set to 120 s
2Profile

Preference profile

src/lib/preferences.ts
  • Languages: Hindi hi, English en, Tamil ta
  • Movie genres: Thriller 53, Sci-Fi 878, Drama 18
  • TV genres: Crime 80, Mystery 9648, Sci-Fi & Fantasy 10765, Drama 18 (TMDB has no TV Thriller)
  • Platforms matched by name, so a renamed or re-numbered provider is still found
3Fetch

Release fetcher and filter

src/lib/tmdb.ts
  • Resolves India provider IDs for the three platforms
  • Movies: digital release (type 4) in India in the last 7 days
  • TV: brand-new shows, or shows whose new season started in the window
  • Filters by language, genre and subscription platform; keeps the 12 most popular
  • Adds runtime or episode count, genre names and the exact platform per title

TMDB API v3

  • /watch/providers (region IN)
  • /discover/movie, /discover/tv
  • /{type}/{id}, /{type}/{id}/watch/providers
  • /genre/*/list
4Judge

Watch-or-skip recommender

src/lib/gemini.ts
  • One batched prompt with the profile and all candidate titles
  • Structured JSON back: verdict, 0–100 match score, two-line synopsis, one-line reason
  • Each call is capped at 15 s, then falls back to the next Flash model

Gemini Flash

  • gemini-flash-latest
  • Fallbacks: gemini-3.5-flash, gemini-flash-lite-latest
5Compose

Digest builder

src/lib/digest.ts
  • Joins TMDB data with Gemini verdicts and sorts by match score
  • If Gemini is unavailable, the digest still goes out without verdicts
  • Sends a "nothing new this week" note when no title matches
6Deliver

Telegram sender

src/lib/telegram.ts
  • HTML formatting with escaped titles
  • Splits between entries to stay under Telegram's 4,096-character limit
  • Fails the run loudly if Telegram rejects a message

Telegram Bot API

  • sendMessage to Naman's chat via @Moodymovies_bot

Web page

src/app/page.tsx is the public homepage. It shows the profile and schedule and has two buttons that call the same API route, so the pipeline can be checked with live data at any time without waiting for Friday.

Known limits

OTT arrival dates

TMDB records release dates and current platforms, not the day a title was added to a platform. An older film newly added to Netflix India may be missed.

"Indie" drama

TMDB has no indie genre, so any Drama passes the filter and Gemini judges how well it fits an indie taste.

Open manual trigger

The homepage buttons need no login so graders can run it. Anyone with the URL can trigger a send.
